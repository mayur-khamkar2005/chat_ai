# Loader Module

## Purpose
The loader module provides a reusable entry point for loading various types of data into the bot. It helps centralize file-based loading logic for intents, knowledge, and other reusable assets.

## Responsibilities
- abstract file loading behavior
- support reusable data access patterns
- simplify future extension points

## Future direction
This module can evolve into a more general resource loading layer for the whole backend.
