# Fuzzy Matching Module

## Purpose
The fuzzy module improves intent matching when a user writes text that is slightly different from an expected pattern. It helps the chatbot remain resilient to typos and imperfect phrasing.

## Responsibilities
- support approximate matching
- improve robustness for misspellings
- increase detection accuracy for informal input

## Future direction
This can later be expanded with dedicated fuzzy metric algorithms and more advanced similarity scoring.
