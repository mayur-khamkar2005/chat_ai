# Context Module

## Purpose
The context module is intended to support conversation state and multi-turn awareness. It helps the chatbot remember what happened earlier in a conversation so replies can feel more coherent.

## Responsibilities
- track conversation context
- provide relevant prior information to the brain
- support future multi-turn reasoning

## Future direction
This module is currently a placeholder and can be expanded with session-based state, short-term memory, and user-specific context management.
