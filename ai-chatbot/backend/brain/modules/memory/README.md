# Memory Module

## Purpose
The memory module is the foundation for long-term or short-term conversational memory. It helps the chatbot retain useful information and use it in future replies.

## Responsibilities
- store user-specific or session-specific facts
- support future memory-aware responses
- keep the chatbot experience more natural over time

## Future direction
The initial version can start with simple in-memory storage and later evolve into persistent storage if the project grows.
