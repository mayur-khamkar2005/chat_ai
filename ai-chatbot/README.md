# AI Chatbot

This project contains the frontend and backend for an AI Chatbot application.

## Directory Structure

- `frontend/`: React application (Vite).
- `backend/`: Node.js Express server.
- `docs/`: Project documentation.

## Setup Instructions

### Prerequisites
- Node.js (v18+ recommended)

### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Frontend Setup
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used
- **Frontend:** React, Vite
- **Backend:** Node.js, Express, Nodemon
- **Other:** CORS, dotenv, Prettier, ESLint
